CC Monitor 便携版
==============

运行要求
--------
- Windows 10/11
- Node.js 已安装并在 PATH 中（命令行运行 `node -v` 验证）
- Claude Code CLI 已安装：`npm install -g @anthropic-ai/claude-code`
- WebView2 运行时（Windows 10 通常已预装，未安装请下载：https://developer.microsoft.com/en-us/microsoft-edge/webview2/）

使用方法
--------
1. 解压到任意目录
2. 双击 cc-monitor.exe 启动
3. 首次使用需在主窗口点击"添加终端"选择工作目录

文件说明
--------
cc-monitor.exe       主程序
WebView2Loader.dll  WebView2 加载库
